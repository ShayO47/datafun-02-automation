# Data Card: Auto MPG Dataset

## Source

Auto MPG dataset from the UCI Machine Learning Repository.

- Source: https://archive.ics.uci.edu/dataset/9/auto+mpg
- Citation: Quinlan, R. (1993). Auto MPG [Dataset]. UCI Machine Learning Repository.
- License: CC BY 4.0

## Purpose

This dataset supports an analysis of automobile fuel economy.

## Records

The dataset contains 398 automobile records.

## Variables Used

- 'mpg' — city fuel economy in miles per gallon
- 'cylinders' — number of engine cylinders

## Other Variables Available

- 'displacement'
- 'horsepower'
- 'weight'
- 'acceleration'
- 'model_year'
- 'origin'
- 'car_name'

## Notes

The 'horsepower' column has some missing values represented by '?'.
This project analyzes 'mpg' and 'cylinders', which are available for the
records used in the analysis.
